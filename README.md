# 🚀 Terraformers: Nano Exodus (테라포머스: 나노 엑소더스)

레밍즈(Lemmings) 스타일의 실시간 전략 SF 샌드박스 액션 퍼즐 웹 게임

---

## 🎮 주요 기능 (Features)
- **10개의 고유한 스토리 맵 & 자동 절차적 맵 생성 (Infinite Procedural Maps)**
- **9가지 나노 특수 스킬 시스템**
  - 🧗 **마그네틱 등반 (Magnetic Climber)**: 수직 벽 등반
  - 🪂 **반중력 슈트 (Anti-Grav Floater)**: 안전한 낙하산 활공
  - ⚡ **플라즈마 커터 (Plasma Cutter)**: 수평 암반 연속 레이저 절삭
  - ⛏️ **대각선 연속 굴착 (Diagonal Mining)**: 대각 방향 쾌속 굴착
  - 🌋 **열핵 융해 드릴 (Thermal Drill)**: 수직 암반 관통
  - 💥 **단일 코어 자폭 (Single Overload Bomb)**: 암반 파괴 및 통로 개척
  - 🪜 **나노 계단 3D 프린팅 (Nano 3D Bridge)**: 대각선 구조물 건설
  - 🛡️ **포스필드 블로커 (Forcefield Blocker)**: 나노봇 이동 방향 반전
  - 🌀 **양자 웜홀 포털 (Quantum Portal)**: 장거리 순간이동 통로
- **스마트 자동 해결 인공지능 (AI Auto-Solver)**
- **반응형 16:9 모바일 & 데스크톱 최적화 인터페이스**
- **Web Audio 기반 실시간 SFX 오디오 엔진**

---

## 🛠️ 실행 방법 (How to Play)
- 최신 웹 브라우저(Chrome, Edge 등)에서 `index.html` 파일을 더블 클릭하여 즉시 실행할 수 있습니다.
